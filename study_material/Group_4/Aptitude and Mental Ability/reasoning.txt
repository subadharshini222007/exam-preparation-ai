# 🔴 TYPE 1: ANALOGY (HARD LEVEL)

---

## 📌 எப்படி கேப்பாங்க:

👉 A : B :: C : ?

## 📌 Keywords:

👉 “same relation”
👉 “similar pattern”

## 📌 Solve Method:

👉 First pair relation கண்டுபிடி
👉 அதே relation apply

---

## 🔥 HARD SOLVED EXAMPLES

### 🧠 Q1

Doctor : Hospital :: Teacher : ?

👉 Relation = Work place
✔ Answer = School

---

### 🧠 Q2

Book : Reading :: Knife : ?

👉 Use → Cutting

✔ Answer = Cutting

---

### 🧠 Q3 (Hard)

Pencil : Write :: Eraser : ?

👉 Opposite function
✔ Remove
